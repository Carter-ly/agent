# 前端展示层（单页聊天网页）

一个聊天式界面：输入框 + 消息气泡（用户 / 助手），支持 **SSE 流式（打字机）** 显示 + **来源标注** + **多轮历史**。

## 技术

- 原生 HTML + CSS + JS（无需构建，打开即用）
- `fetch` 读取 `/api/ask` 的 SSE 流，逐 token 渲染
- 多轮历史由前端维护，随每次请求带给后端

## 运行

由后端直接托管，启动后端后访问 `http://127.0.0.1:8000/` 即可：

```bash
# 在 proj/ 目录下
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

前端只做展示和发请求，不接触 RAG / Agent 逻辑。
